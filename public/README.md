# SURF Design System Assets

Copy these files from the `surf-design-system` folder to this directory:

## Fonts
Copy all font files from `surf-design-system/fonts/` to `public/fonts/`:
- Nunito-*.ttf (all Nunito font files)
- SourceSansPro-*.ttf (all Source Sans Pro font files)

## Logos
Copy logo files from `surf-design-system/assets/logo/` to `public/assets/logo/`:
- SURF_fc.svg (full color mark with curl)
- SURF_diap.svg (wordmark only, for dark backgrounds)

## Favicon
Copy favicon from `surf-design-system/assets/favicon/` to `public/`:
- surf-favicon.ico

## Directory Structure
```
public/
├── fonts/
│   ├── Nunito-*.ttf
│   └── SourceSansPro-*.ttf
├── assets/
│   └── logo/
│       ├── SURF_fc.svg
│       └── SURF_diap.svg
└── surf-favicon.ico
```
